# shorts-factory-app

個人で作っているショート動画(YouTube ショート / Instagram リール)の制作ツールが、
できた動画ファイルを **作者自身の Google Drive** に置くために使う Google OAuth アプリです。

- 使う人: このリポジトリの持ち主ひとりだけ
- 使う権限: Google Drive の `drive.file`(このアプリが自分で作ったファイルだけを読み書きできる)
- 一般向けのサービスではありません

プライバシーポリシー: [PRIVACY.md](PRIVACY.md)

---

shorts-factory-app is a personal OAuth app used by the owner's short-video production tool
to upload finished videos to the owner's own Google Drive (`drive.file` scope only).
It is not a public service. Privacy policy: [PRIVACY.md](PRIVACY.md)
